# Security policy

Security fixes target the current main branch. Include the affected version or
commit, operating system, relevant configuration, impact, and minimal
reproduction steps. Do not include credentials or private data.

Report suspected vulnerabilities privately through
[GitHub security advisories](https://github.com/Kosinkadink/dinkster-aimdo/security/advisories/new),
not a public issue. Ordinary bugs belong in this repository's issue tracker.

Native allocation and offloading run inside the caller's process. Use trusted
applications, model artifacts, and native wheels. Third-party dependencies have
their own licenses and security policies.
